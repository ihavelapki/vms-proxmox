# vms-proxmox

A simple, secure, documented Terraform VM builder for a standalone Proxmox VE 9.x server.

The project is currently documenting and validating its architecture; Terraform VM resources have not been implemented.

## Project documentation

- [Current architecture](docs/architecture.md)
- [Current approved decisions](docs/decisions.md)
- [Stage 0 background and detailed analysis](docs/stage-0/architecture.md)

The current task prompt determines what work is authorized. Documentation does not authorize Terraform apply/destroy, state changes, template preparation, Proxmox host changes, GitLab configuration, or network changes.
